# KNK_25_Gr20

Ky projekt është një sistem interaktiv i zhvilluar në Java (JavaFX) i cili lehtëson procesin e aplikimit dhe menaxhimit të bursave për studentët. Sistemi do të mundësojë:

  - Aplikimin për bursa në mënyrë të thjeshtë dhe të strukturuar.
  - Menaxhimin e bursave dhe gjurmimin e statusit të tyre.

Ky projekt është zhvilluar nga grupi i studentëve:
Olsa Domi, Riga Zubaku, Olti Krasniqi, Bleron Baftiu, Rreze Ejupi, Valmir Mustafa

Informacione më të detajuara rreth projektit, do të përditësohen gjatë punës në vijim, në mënyrë sistematike.
